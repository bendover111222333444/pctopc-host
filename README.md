PC to pc is a software me bendover make it allows connection between two computers one with app running and one with a browser running.
The app version wont work if you just download and open the index.html.
Additionally if it the exe doesnt work due to admin permissions etc. Download the binary and run windowsStart.bat or linuxmax.sh depending on what platform you are on. Then it will work as long as you have node installed. The exe version does not need node but does need some permmissions to run.
Also please download the binary from the green code button for the most recent version although it might not be stable.
